# הוראות דחיפת v10 ל-GitHub

## שלבים

1. פתח טרמינל בריפו המקומי שלך (IMUD_TORANI)
2. ודא שאתה על branch V15: `git checkout V15`
3. העתק את כל הקבצים מ-v10-release/ לתיקיית הריפו
4. הרץ:
   ```bash
   git add -A
   git commit -m "v10: פיצול רשימות גופנים + דוח עימוד מועשר + P2.5 + .nojekyll"
   git push origin V15
   ```
5. פתח https://suginach.github.io/IMUD_TORANI/ ובדוק
